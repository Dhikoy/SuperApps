================================================================================
2. PERMISSION
================================================================================

  hr:view       → Lihat dashboard HR & modul read-only
  hr:manage     → Kelola master data HR (divisi, jabatan, rekrutmen, dll)
  stock:manage  → Input stock opname (khusus Admin, tanpa modul keuangan penuh)

  Role:
    HRD         → hr:view, hr:manage, stock:manage
    ADMIN       → hr:view, hr:manage, stock:manage
    SUPER_ADMIN → semua permission HR


================================================================================
3. STOCK OPNAME UNTUK ADMIN
================================================================================

  Admin dapat input stok opname via:
    /dashboard/hr/stock-opname

  Permission: stock:manage (bukan finance:view)

  Keuangan tetap pakai:
    /dashboard/keuangan/stock  (finance:view + finance:submit)

  API sama: /api/finance/stock dan /api/finance/stock/opname
  Mendukung stock:manage ATAU finance:submit
