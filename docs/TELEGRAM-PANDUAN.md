# Panduan Telegram — SuperApps BCI

Bot: [@Appsbci_bot](https://t.me/Appsbci_bot)  
Website tetap lengkap.

## Hubungkan akun

Profil Saya → **Hubungkan Telegram** → `/start KODE` (10 menit).

## Perintah utama

Ketik `/menu` untuk tombol.

| Perintah | Fungsi |
|----------|--------|
| `/hariini` `/jadwal` `/status` | Ringkasan & jadwal |
| `/clockin` `/clockout` | Absensi lokasi + foto |
| `/koreksi` | Koreksi jam absen → HRD (setujui juga di web: **HR → Koreksi Absensi**) |
| `/izintelat` | Izin terlambat hari ini |
| `/cuti` `/lembur` `/dinas` `/dana` | Pengajuan |
| `/sisacuti` `/slip` | Cuti & slip PDF |
| `/tasks` `/taskprog` `/onboarding` | Task & onboarding |
| `/pending` `/bayardana` | Approval & bayar + bukti |
| `/laporan` | Laporan mingguan (HR/Super Admin) |
| `/broadcast` | Siaran HRD |
| `/batal` `/unlink` `/help` | Batal / putus / bantuan |

## Notifikasi otomatis

Absensi H-5/telat/pulang · digest 07:00 · shift H-30 · cuti/lembur/dana/dinas/koreksi · task · onboarding · stok · aset H-7/H-1/≤3 hari · ulang tahun & kontrak (HR) · Paid/Realized
